# Testing

## Automated

`npm test` covers the existing project tests plus MVMCMD command/catalog/persistence/URL tests.

The CI workflow runs:

1. `npm ci`
2. `npm run typecheck`
3. `npm run lint`
4. `npm test`
5. `npm audit --audit-level=high`
