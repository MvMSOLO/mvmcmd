# Changelog

## 1.0.0

- separated static web builds from deployment-time database migrations
- added production Android APK verification and manifests
- added a real Windows x64 launcher executable with the built web bundle embedded
- synchronized package and Android version metadata
- added PackageManager-backed dynamic Android bindings with persistence/migration
- removed false-positive native launch success reporting
- added durable WebRTC signaling, session-token validation, payload limits and runtime TURN configuration
- expanded automated MVMCMD contract tests
